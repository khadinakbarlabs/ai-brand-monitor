# Security reporting

Do not publish tokens, sensitive reports or exploitable details in public issues. Use [GitHub private vulnerability reporting](https://github.com/khadinakbarlabs/ai-brand-monitor/security/advisories) and select **Report a vulnerability**. Private vulnerability reporting is enabled for this repository; a GitHub account is required. Include the plugin version, affected skill, expected behavior and a synthetic or redacted reproduction. Keep credentials, customer records and private run data out of the report.

The package contains no service, auth intake, dependency installer or startup hook. It guides a user-owned official CLI with fixed Actors and explicit budgets. Its security boundaries are documented in skills/ai-brand-monitor/references/security.md. The live Apify Actors and provider services remain separate dependencies.
