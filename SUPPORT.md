# AI Brand Monitor support

Publisher: Khadin Akbar.

Use [GitHub Issues](https://github.com/khadinakbarlabs/ai-brand-monitor/issues) for setup questions, feature requests and reproducible bugs. A GitHub account is required to open an issue. Vulnerabilities use the private route in [security reporting](SECURITY.md). No response-time commitment is made.

For a bug report, include the plugin version, host type, CLI version, affected skill, expected behavior and a redacted example. Never post credentials, customer data, private prompts, account identifiers or full run logs. Use the synthetic example for a reproducible public report when possible.

Authentication problems belong to the official local Apify login flow. Paid-run errors require checking the correct Actor/build, run status, dataset coverage and account budget. A successful health check is not proof of measured visibility. Provider interruptions or missing answers remain unknown in the report.

See SECURITY.md for security concerns. Do not expose vulnerability details or exploit data in a public issue.
