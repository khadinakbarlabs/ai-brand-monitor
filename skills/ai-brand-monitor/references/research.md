## What changed in this implementation

AI Brand Monitor keeps the workflow in readable skills and uses the publisher's existing Actors via the official external Apify CLI. It does not bundle the upstream services, databases, scripts, MCP servers, skill text, browser scrapers or scoring systems. All instructions and the static report design were written for this plugin. Upstream materials informed concepts; no upstream code or prose is redistributed. Each project's license was checked before considering reuse.

The plugin adopts stable buyer prompt panels, explicit coverage, the distinction between a mention and a recommendation, local campaign continuity, source provenance, understandable reports and action follow-up. It changes measurement to fit the actual Actor contracts: weighted aggregate mention share, no unsupported per-competitor frequency or rank, lexical sentiment caveats, and verified source URLs separated from domain-in-text flags.

No readiness rubric becomes an observed visibility score. The research found conflicting `llms.txt` and crawler heuristics, so those are not scored as proof of citation or guaranteed ranking. Popularity statistics and anecdotal lift claims are not copied into the listing. Consumer browser monitoring implementations are not described as equivalent to this API-backed measurement.
