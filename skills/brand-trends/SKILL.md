# Brand trends

Read the selected campaign's state and evidence only. Use [measurement](../ai-brand-monitor/references/measurement.md) and [state](../ai-brand-monitor/references/state.md). If there is only one valid run, describe a baseline; do not invent a trend.

Compare cells by campaign, exact prompt, platform, prompt class and replicate identifier. Require unchanged brand/domain, aliases, competitor set and prompt language/market for a comparable metric. Changed models or Actor builds form separate cohorts or a clearly labeled break. New questions belong to an expanded-panel view, not the historical denominator. Use the intersection of valid cells and show both matched-cell coverage and full-panel coverage.

Report percentage-point changes for mention/citation rates; distinguish them from relative percentage change. Do not carry forward missing observations or replace failed checks with zeros. Never select the best duplicate/repeated answer. If replicate samples exist, retain all authorized replicates and show their spread; label small panels as directional. A single changed answer is a lead to investigate, not proof of a market-wide shift.

Show improved and declined questions, then stable high-value opportunities. Explain model/version changes, incomplete sources and lexical sentiment uncertainty. The same exported answers must produce the same displayed metrics; round only for presentation.

Review previously accepted actions: planned, completed, deferred or rejected. Record implementation date and public evidence if the user provides it. A later improvement is temporal association, not proof the action caused it. Recommend a bounded next check through brand-audit only if new collection is requested and budgeted.

Save a comparison report, the matched-cell evidence index, updated actions and state. Cross-brand portfolio summaries must preserve each brand's own panel and denominator; do not blend different campaigns into one ranking.
